# Healthcare Backend

Scaffold for University Health Center backend.

Quick start:

1. Copy your Firebase service account values into `.env` (FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, FIREBASE_PRIVATE_KEY).
2. Configure MySQL credentials in `.env`.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm run dev
```

API routes are mounted under `/api` and basic placeholders exist for models/controllers/routes.
